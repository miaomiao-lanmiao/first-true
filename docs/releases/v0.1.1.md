# Echo v0.1.1

Maintenance release draft, 2026-10-23 (Asia/Shanghai).

- Restore legacy title-based session filenames containing spaces, retaining
  compatibility with underscore filenames from the previous maintenance version.
- Show CLI/TUI sessions in the Web list using the actual validated filename as
  the session ID. Existing records are not rewritten during listing/reading.
- Fetch full saved messages when opening a session after page reload, restoring
  both visible conversation text and the history used by the next chat request.
- Skip invalid session records in lists and return a sanitized 422 for direct
  requests for malformed stored data. Existing corrupt files are not deleted.
- Redact credential fields nested inside configuration lists without mutating
  the saved configuration.
- Centralize the source/CLI version and modernize SPDX license metadata.

24 local tests passed, including legacy-session and nested-redaction regressions.
The wheel/source archive, installed command and browser workflow are verified.
Four Linux/Windows Python 3.11/3.13 hosted checks are required before this draft.

Install the attached wheel in a virtual environment:

```sh
python -m pip install ./echo_chat-0.1.1-py3-none-any.whl
echo-chat --version
```

The application remains a local alpha prototype with plaintext user storage.
No real-provider request or PyPI publication was performed during this update.
