# Echo 使用说明书

> Echo 是一个可定制的 AI 编程工作台（Web UI），支持多模型对话、技能系统（Skills）、MCP 工具接入、语音交互（TTS/STT）、自定义头像与定时任务。
> 作者：懒喵大王喵

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows / macOS / Linux |
| Python | ≥ 3.10（推荐 3.11 / 3.12） |
| 网络 | 调用大模型需要可访问对应服务商 API |
| 浏览器 | Chrome / Edge（语音功能依赖其 Web Speech / 麦克风权限） |

## 三、安装

```bash
# 进入项目目录
cd echo

# 方式一：以可编辑包安装（推荐）
pip install -e .

# 方式二：仅安装依赖
pip install fastapi uvicorn pydantic httpx pyyaml typer rich pygments textual
```

安装成功后会注册命令：`echo`（终端/TUI/Web 入口）。

## 四、启动

### Web 工作台（主推）

```bash
echo web                      # 默认 http://127.0.0.1:8000
echo web --port 8123          # 指定端口
echo web --host 0.0.0.0       # 允许局域网访问（注意安全）
```

启动后浏览器打开对应地址即可。

### 终端 TUI（旧版）

```bash
echotui          # 控制台 TUI 模式（pip install -e . 后可用）
```

### 命令行直接提问

```bash
echo chat "用 Python 写一个快速排序"
```

## 五、配置 API Key 与模型

1. 打开界面右上角 **⚙ 设置**。
2. 选择「服务商」与「模型」，粘贴对应 **API Key**（留空则不修改，填 `clear` 可清除）。
3. 点击保存。

支持的服务商与模型：

| 服务商 | 示例模型 | 需要 Key |
|--------|----------|----------|
| OpenAI | gpt-4o / gpt-4o-mini / gpt-4-turbo / gpt-3.5-turbo | 是 |
| DeepSeek | deepseek-chat / deepseek-reasoner | 是 |
| Anthropic | claude-sonnet-4 / claude-3.5-sonnet / claude-3.5-haiku | 是 |
| Google Gemini | gemini-2.0-flash / gemini-1.5-pro / gemini-1.5-flash | 是 |
| Ollama（本地） | llama3.1 / qwen2.5 / mistral / codellama | 否（需本地运行 Ollama） |

> 配置保存在用户目录：`~/.config/echo/config.json`

## 六、功能详解

### 1. 会话（Sessions）
- 左上角 **＋** 新建会话，点击会话切换，悬停 **🗑** 删除。
- 消息自动持久化，刷新或重开浏览器不丢失。

### 2. 技能 Skills
- 右侧「技能」标签页管理。每个技能是一个 `SKILL.md` 文件，格式：
  ```markdown
  ---
  name: git-commit
  description: 生成规范 commit 信息
  enabled: true
  ---

  审查 staged 改动，生成 conventional commit 信息。
  ```
- 启用的技能会在每次对话时自动注入到系统提示中。
- 开关即时生效，无需重启。

### 3. MCP 服务器
- 右侧「MCP」标签页添加服务器（名称 / URL / Token / 启用）。
- 存储于 `~/.config/echo/mcp.json`。

### 4. 主题
- 顶栏 **◐** 循环切换 4 套主题：GrokNight / TokyoNight / RosePine / Oscura。
- 选择会持久化。

### 5. 语音系统（重点）
在「⚙ 设置 → 语音系统」中配置：

**AI 能发声（TTS 语音播报）**
- 顶栏 **🔊** 切换开/关；每条 AI 回复下方有「🔊 朗读」按钮。
- 引擎可选：
  - **浏览器原生**：选择本机已安装的语音（如微软晓睿/云希），可调语速。
  - **自定义 API**：填写你的 TTS 接口地址、Key、声音参数。调用约定见下文「进阶」。

**能语音指挥（STT 语音识别）**
- 输入框左侧 **🎤** 按钮：点一下开始聆听，实时转文字填入输入框，**说完自动发送**（再点一次停止）。
- 引擎可选：
  - **浏览器原生**：Chrome/Edge 内置识别，可选语言（中/英/日/韩）。
  - **自定义 API**：点 🎤 录音，音频自动 POST 到你的识别接口，返回文本后发送。

### 6. 自定义头像
- 「⚙ 设置 → 外观 → AI 头像」：填写图片 URL，或点「上传」选择本地图片（自动转 base64 存储）。
- 保存后对话中的 AI 头像即时替换。

### 7. 定时任务
- 右侧「定时」标签页，**＋** 新建。
- 两种触发方式：
  - **每隔 N 分钟**：如每 60 分钟运行一次。
  - **每天固定时间**：如每天 09:00。
- 任务会用当前技能与模型生成内容，结果写入一个专属会话（标题 `⏰ 任务名`）。
- 卡片支持：启用开关、立即运行、编辑、删除，并显示上次运行时间/成功失败/预览。
- 后台调度器每 20 秒检查一次到期任务（无 API Key 时会优雅记录失败，不会崩溃）。

## 七、进阶：自定义语音 API 对接

### 自定义 TTS（语音合成）
Echo 会向你的接口发送：

```http
POST <你的TTS地址>
Authorization: Bearer <你的Key>        # 可选
Content-Type: application/json

{ "text": "要朗读的文本", "voice": "<声音参数>", "lang": "zh-CN", "rate": 1.0 }
```

返回支持两种格式：
- 直接返回音频二进制（`Content-Type: audio/*`）→ 自动播放。
- 返回 JSON：`{ "audio": "<base64 或 URL>" }` 或 `{ "url": "<音频地址>" }` → 自动播放。

### 自定义 STT（语音识别）
Echo 会录制麦克风音频（webm），以表单形式发送：

```http
POST <你的STT地址>
Authorization: Bearer <你的Key>        # 可选
Content-Type: multipart/form-data

file: <音频二进制>
lang: zh-CN
```

返回 JSON：`{ "text": "识别出的文字", "transcript": "...", "result": "..." }`（取其中任一字段）。

> 这样你就可以把 Echo 接到自己部署的 Whisper、Azure Speech、或任何私有语音服务上。

## 八、数据与存储位置

所有用户数据位于 `~/.config/echo/`：

```
~/.config/echo/
├── config.json        # 服务商/模型/Key/语音/头像 等设置
├── sessions/          # 会话记录（<id>.json）
├── skills/            # 技能（<slug>/SKILL.md）
├── mcp.json           # MCP 服务器配置
├── tasks.json         # 定时任务
└── avatar.txt         # 自定义头像（base64 或 URL）
```

## 九、常见问题

**Q：模型下拉是空的？**
A：请先在设置里选择服务商并保存；若仍为空，确认该服务商在提供商列表中存在对应模型。

**Q：语音没声音 / 麦克风用不了？**
A：语音依赖 Chrome / Edge 的 Web Speech API，且需在 `localhost` 或 HTTPS 下、并授权麦克风。Firefox 对 Web Speech 支持有限，建议用 Chrome/Edge。

**Q：自定义语音 API 没反应？**
A：先在设置里把引擎切到「自定义 API」并填好地址；TTS 返回需为音频或含 `audio/url` 字段的 JSON，STT 返回需含 `text/transcript/result` 字段。

**Q：定时任务不执行？**
A：后台调度器每 20 秒轮询；确保任务已「启用」且服务正在运行。无 API Key 时任务会记录失败但不影响其他功能。

**Q：端口被占用？**
A：用 `echo web --port <其他端口>` 换端口。
