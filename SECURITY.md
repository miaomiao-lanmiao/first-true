# Security policy

Echo is an alpha prototype for the current user's local machine. Remote users,
multi-user deployments and public hosting are not supported. AI and optional
speech calls transmit the selected content to configured services.

Report suspected issues through private GitHub vulnerability reporting when
available. Otherwise request a private contact channel without posting secrets
or exploitation details. Do not put real keys in issues, logs or screenshots.

Saved configuration and conversations are plaintext under the selected data
directory. The application does not provide encrypted credential storage.
Use environment-managed keys and trusted local files. User-supplied skills and
provider replies should be reviewed before acting on their suggestions.

The latest source on main receives maintenance. No PyPI release is claimed by
this repository review; install from the reviewed source checkout.
