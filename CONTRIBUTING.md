# Contributing

Use the root README to create a virtual environment and install the development
requirements. Create a branch, make a focused fix, and add a behavioral regression
test using temporary storage and synthetic credentials. Run the documented tests
and packaging checks before opening a PR.

Bug reports should include OS/Python versions, the command, expected and actual
results, and a minimal sanitized reproduction. Do not upload private sessions,
credentials or full personal configurations. 中文反馈同样欢迎。
